## Hello, I’m Marsha.

I’m an AI and data engineer with a background spanning machine-learning research, data integration, and production software development. I’m interested in how information is represented inside intelligent systems and how reliable data foundations make those systems possible.

At Hiroshima University’s Data Analysis and Modelling Laboratory, I studied cross-lingual knowledge editing in large language models through an Indonesian-English case study. My work involved experimental evaluation, model-performance analysis, and neuron-activation analysis using Python and PyTorch. Earlier, my undergraduate thesis explored stock prediction from market transaction data using recurrent neural networks.

Before graduate study, I worked on enterprise software at CamLine Indonesia and interned at Mekari. These roles gave me experience with production systems, automation, testing, CI/CD, MongoDB, and Apache NiFi data workflows.
